01 / Formulas

Variable: uint32_t t. Arithmetic wraps at 32 bits; output wraps to uint8_t. Supports arithmetic, bitwise, comparison, logical and ?: operators. No statements, functions, casts or side effects.

02 / Color LUT tables

CRGB lookupTable[64]

Appends colors to the selected palette without stopping playback (64 maximum). Indexed left to right. Remaining entries are zero-filled and excluded from selection and shuffling. Black can also be an explicit active color.

03 / Simulation

t advances once per frame. Color index advances with 4% probability per frame. Formula selection stays manual. Seeded randomness is reproducible here; it does not reproduce ESP32 random().

04 / Export PNG sequence

PNGs are horizontal (64 × 16 at scale 1), rotated 90° clockwise from the preview. Exports restart from the applied settings, independent of playback. Frame 0 contains the first generated row. ZIP includes settings and libraries as project.json. Apply pending edits before exporting.
